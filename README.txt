🦆 덕구 — macOS 데스크탑 펫

▶️ 실행 방법
  덕구.app 을 더블클릭하세요. 끝!

📂 폴더 구성
  덕구.app         ← 이거 더블클릭하면 실행
  rebuild.sh      ← 코드 수정 후 다시 빌드할 때 사용 (개발자용)
  src/            ← 소스 코드 + 빌드 부산물 (편집할 일 없으면 안 봐도 OK)

🔄 다시 빌드하려면 (코드 수정 후)
  터미널에서:
    ./rebuild.sh

🌀 처음 실행 시 보안 경고가 뜨면
  덕구.app 에 우클릭 → "열기" → "허용"
  (Apple 미서명 앱이라 한 번만 거치면 됨. 이후엔 그냥 더블클릭으로 OK)
